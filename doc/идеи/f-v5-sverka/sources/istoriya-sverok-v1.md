### 2. Общее описание

В разделе «Сверка застрахованных» должен отображаться список проведенных сверок, чтобы к ним можно было вернуться: открыть результат, скачать исходный файл, повторить сверку с тем же файлом.

Постановка дополняет постановку «Сверка застрахованных с данными СК»: сверки уже сохраняются с исходным файлом, статусом и результатом.

Действия

Клик по строке должен открывать экран результата сверки.

Кнопка «Повторить» в строке должна запускать новую сверку с теми же ГК, СК и файлом по текущим данным системы. Прежняя сверка не меняется.

Фильтры: ГК, СК, статус. Сортировка — по дате, новые сверху.

В список попадают только запущенные сверки; файлы, не прошедшие проверку, не сохраняются.

Если сверок нет, должно отображаться I1.

Критерии приемки

В разделе отображаются сверки всех пользователей, новые сверху, с колонками из таблицы «Колонки списка».

Клик по сверке «Готова» открывает результат — такой же, как на момент сверки.

По ссылке «Исходный файл» скачивается загруженный файл.

«Повторить» создает новую сверку с теми же ГК, СК и файлом; прежняя сверка не меняется.

Фильтр по статусу «Ошибка обработки» оставляет только такие сверки.

Если сверок нет, отображается «Сверок пока нет».
