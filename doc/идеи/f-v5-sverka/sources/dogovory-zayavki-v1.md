### 2. Общее описание

В результате сверки по каждой строке расхождения должны отображаться договоры ЗХ и заявки по нему со ссылками на их карточки в системе. Так пользователь сразу видит, было ли с нашей стороны действие (заявка на прикрепление, открепление, изменение) или движение нужно уточнять у СК.

Постановка дополняет постановку «Сверка застрахованных с данными СК»: экран результата и выгрузка в Excel уже должны быть реализованы.

Требования: ссылки на экране результата (FR-01), те же данные в выгрузке Excel (FR-02).

Как работает

Пользователь открывает результат сверки.

Система по каждой строке находит договоры ЗХ и заявки по нему на текущий момент.

Пользователь нажимает на номер договора или заявки — карточка открывается в новой вкладке.

Новые колонки

| Колонка | Что показывает |
|---|---|
| Договоры ЗХ | Все договоры ЗХ с ЮЛ, в том числе прошлые. Номер — ссылка на карточку договора |
| Заявки ЗХ | Заявки по ЗХ: номер, тип (прикрепление, открепление, изменение), статус, дата. В строке видны 3 последние, остальные — по ссылке «еще N». Номер — ссылка на карточку заявки |
| Действия с нашей стороны | «Есть заявки» или I1 |


Откуда берутся данные

Для строк, где ЗХ найден в системе, должны показываться все его договоры и все заявки по нему в рамках этих договоров.

Для строк «Есть в СК, нет в системе» система должна искать ЗХ ГК с такими же ФИО и датой рождения — в любых статусах и с любыми СК. Если найден, показываются его договоры и заявки (например, открепление или отклоненная заявка на прикрепление). Если не найден — I1.

Данные должны браться на момент открытия экрана, а не на момент сверки: так видны действия, сделанные уже после сверки.

Ссылки должны открываться в новой вкладке.

| I1 | По ЗХ нет заявок | «Действий с нашей стороны не найдено» | Колонка «Действия с нашей стороны» |

Создание заявок с экрана результата

Критерии приемки

В списке расхождений есть колонки «Договоры ЗХ», «Заявки ЗХ», «Действия с нашей стороны».

Номер договора открывает карточку договора в новой вкладке.

В «Заявки ЗХ» видны номер, тип, статус и дата трех последних заявок; остальные открываются по «еще N».

Для строки «Есть в СК, нет в системе», если в ГК есть открепленный ЗХ с теми же ФИО и датой рождения, отображаются его договоры и заявка на открепление.

Для ЗХ без заявок отображается «Действий с нашей стороны не найдено».

Заявка, созданная после сверки, отображается при следующем открытии результата.

#### FR-02. Договоры и заявки ЗХ в выгрузке Excel

| Что нужно сделать | На лист «Расхождения» выгрузки результата сверки должны добавиться те же колонки «Договоры ЗХ», «Заявки ЗХ» и «Действия с нашей стороны». Правила

Данные должны совпадать с экраном на момент выгрузки.

Все заявки ЗХ должны выводиться в ячейке через перенос строки, без ограничения «3 последние».

Критерии приемки

На листе «Расхождения» есть колонки «Договоры ЗХ», «Заявки ЗХ», «Действия с нашей стороны».

Номера договоров и заявок на листе открывают карточки в системе.

На листе «Запрос в СК» этих колонок нет.
