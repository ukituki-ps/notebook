## Отношения между постановками (заявлено в самих документах)

1. Базовая («Сверка застрахованных с данными СК» v2) — самодостаточна:
   раздел, загрузка файла, проверки, сопоставление, экран результата, выгрузка
   в Excel.
2. «История сверок» дополняет базовую: список прошлых сверок, открыть
   результат, скачать исходный файл, повторить сверку. Опирается на то, что
   базовая уже сохраняет сверки (файл, статус, результат).
3. «Договоры и заявки ЗХ в результате сверки» дополняет базовую: колонки
   «Договоры ЗХ», «Заявки ЗХ», «Действия с нашей стороны» на экране результата
   и на листе «Расхождения»; ссылки на карточки; данные на момент открытия.
   Требует, чтобы экран результата и выгрузка уже были реализованы.

Следствие для планирования: дополнения (2) и (3) не могут быть реализованы
раньше базовой постановки (1). Порядок зависит от базовой части.

## Инвентарь требований (для intent-trace)

### Базовая постановка (v2)

- **FR-01. Загрузка файла и запуск сверки.** Раздел «Сверка застрахованных»;
  выбор ГК и СК (СК — только с договорами с ЮЛ выбранной ГК; поле неактивно до
  выбора ГК; сброс при смене ГК); скачивание шаблона
  «Шаблон сверки застрахованных.xlsx»; загрузка одного .xlsx (drag&drop или
  выбор); «Запустить сверку» активна только при ГК+СК+файл; проверки E1–E7
  (формат, лимит размера, обязательные колонки, наличие строк, обязательные
  поля, даты, договор среди договоров ГК↔СК); все ошибки сразу в таблице
  «Строка / Колонка / Ошибка», ГК/СК/файл сохраняются; пустые строки
  пропускаются. Шаблон: колонки № договора\*, ФИО\*, Дата рождения\*,
  Программа\* (обязательные), Тип программы, Страхователь, № полиса СК, Дата
  начала программы; поиск колонок по названию, порядок/лишние колонки — не
  ошибка. Раздел недоступен пользователям клиентов (HR).
- **FR-02. Сопоставление и категории расхождений.** Сверяются только ЗХ
  «Прикреплен». Сравнение ФИО/программы/договора точно, кроме регистра и
  лишних пробелов (в т.ч. «е»/«ё», точки, суффиксы — расхождения). Договор —
  любой договор ЗХ, включая прошлые. Категории: Совпало; Есть в СК, нет в
  системе (+ комментарий «В системе откреплен»); Есть в системе, нет в СК;
  Другое ЮЛ; Расхождение в ФИО; Расхождение в дате рождения; Расхождение по
  программе («Отличие только в знаках» / «Другая программа»); Доп. программа
  в СК; Дубль в списке СК; Задвоение у СК; Дубль в системе; для справки — «В
  процессе у нас», «Переход между ЮЛ». Особые случаи: несколько подходящих ЗХ
  → «Найдено несколько ЗХ» + «Дубль в системе»; основная+дополнительная
  программа одного ЗХ — не дубль; отличие в 2+ частях ФИО — пара не ищется;
  ЗХ «в процессе» без строки в файле — только в свод. Результат фиксируется на
  момент сверки и не пересчитывается. Статусы: «Обрабатывается», «Готова»,
  «Ошибка обработки». Не входит: нечёткий поиск, изменение данных ЗХ.
- **FR-03. Экран результата.** Шапка (ГК, СК, дата/время, кто запустил,
  статус, ссылка на исходный файл, «Выгрузить в Excel»); предупреждения W1
  (договоры ГК↔СК, которых нет в файле) и W2 (расхождение численности в 2+
  раза); свод по договорам с итоговой строкой и фильтрацией кликом по числу;
  список расхождений (колонки категория/договор/ЮЛ/ФИО СК/ФИО система/ДР СК/ДР
  система/программа СК/программа система/№ полиса/статус ЗХ/комментарий) с
  подсветкой отличающихся значений; фильтры (категория — несколько, договор,
  поиск по ФИО, «Показывать для справки» вкл. по умолчанию); сортировка по
  порядку категорий, затем по ФИО; I1 «Сверка выполняется…» до готовности,
  автообновление без перезагрузки; I2 «Расхождений не найдено». Не входит:
  ссылки на договоры/заявки ЗХ (это дополнение 3), отметки «обработано» и
  пользовательские комментарии.
- **FR-04. Выгрузка в Excel.** Кнопка активна только для «Готова» (иначе E8
  «Выгрузка доступна после завершения сверки»); файл
  «Сверка <ГК> <СК> <ДД.ММ.ГГГГ>.xlsx», независимо от фильтров; листы «Свод по
  договорам» (+дата, ГК, СК, правила), «Расхождения» (то же, что на экране,
  с подсветкой), «Запрос в СК» (только категории с текстом запроса; колонка
  «Ответ СК» пустая; без «Дубль в системе», «В процессе у нас», «Переход между
  ЮЛ»); Arial, шапка с заливкой, фильтры, закреплённая шапка. Таблица «Что
  запросить у СК» — как в постановке. Не входит: загрузка ответа СК, отправка
  запроса из системы.

### Дополнение «История сверок» (v1)

- **FR-01. Список сверок.** В разделе под формой запуска — список сверок всех
  пользователей, новые сверху; колонки: дата/время, ГК, СК, кто запустил,
  статус, «Расхождений» («Итого расхождений»; для не-«Готова» — «—»), исходный
  файл (скачивание), действия; клик по строке открывает результат; «Повторить»
  запускает новую сверку с теми же ГК/СК/файлом по текущим данным, прежняя не
  меняется; фильтры ГК/СК/статус; сортировка по дате; в список попадают только
  запущенные сверки; I1 «Сверок пока нет». Не входит: удаление сверок,
  сравнение двух сверок.

### Дополнение «Договоры и заявки ЗХ» (v1)

- **FR-01. Экран результата.** Колонки «Договоры ЗХ» (все договоры ЗХ с ЮЛ,
  включая прошлые; номер — ссылка на карточку в новой вкладке), «Заявки ЗХ»
  (номер — ссылка, тип «прикрепление/открепление/изменение», статус, дата; 3
  последние в строке, остальные по «еще N»), «Действия с нашей стороны»
  («Есть заявки» / I1 «Действий с нашей стороны не найдено»). Данные — на
  момент открытия экрана, а не сверки. Для «Есть в СК, нет в системе» — поиск
  ЗХ ГК с теми же ФИО и ДР в любых статусах и с любыми СК; если найден,
  показываются его договоры и заявки. Не входит: создание заявок с экрана.
- **FR-02. Выгрузка Excel.** Те же три колонки на листе «Расхождения»,
  гиперссылки на карточки, все заявки (без лимита 3) через перенос строки;
  данные совпадают с экраном на момент выгрузки; на листе «Запрос в СК» этих
  колонок нет.

## Открытые вопросы из постановок (перенесены как есть)

- База: лимит размера файла (E2) не задан числом; адреса/маршруты карточек и
  фильтров не заданы.
- История: срок хранения сверок и исходных файлов не задан; «видны сверки
  всех пользователей» — подтверждено предложением, но статус «Открыт».
- Договоры/заявки: 3 последние заявки — «Подходит» (открыт); период — «за весь
  период в рамках договоров ЗХ» (открыт); адреса карточек договора и заявки не
  заданы; названия типов и статусов заявок не сверены с системой.
- Во всех трёх: «сверка с кодом не проводилась — сверить с разработчиком на
  груминге».
