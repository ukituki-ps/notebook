# Content spec — «Сверка застрахованных» (запуск + история)

Шаблон: `tpl-sverka-launch`. Один маршрут `/sverka`, две зоны: форма запуска
(верх) и история сверок (низ). Никаких модальных окон: ошибки файла и
результаты действий показываются inline.

> Терминология состояний. В постановках код `I1` перегружен: в базовой v2 это
> «Сверка выполняется…», в истории — «Сверок пока нет», в дополнении 3 —
> «Действий с нашей стороны не найдено». В UI используются только тексты;
> идентификаторы состояний — `S-*` из `state-matrix.json`.

## 1. Анатомия экрана (сверху вниз)

1. Заголовок страницы и подзаголовок.
2. Карточка «Новая сверка»: ГК → СК → шаблон → файл → запуск.
3. Inline-ошибки файла (E1/E2) под зоной загрузки.
4. Сводка ошибок файла (E3–E7) с таблицей «Строка / Колонка / Ошибка».
5. Карточка «История сверок»: заголовок, счётчик, фильтры, список.
6. Inline-статус действий списка (`aria-live`), не toast.

### 2.1. Обязательность и порядок

- Обязательны: ГК, СК, файл. «Скачать шаблон» не обязательна и не блокирует запуск.
- Смена ГК сбрасывает СК и список СК; файл сохраняется. Сброс объявляется:
  «Группа компаний изменена. Выберите страховую компанию.»
- После любой ошибки файла ГК, СК и выбранный файл остаются как были.
- Повторный выбор файла заменяет предыдущий без подтверждения.

## 3. Ошибки файла E1–E7

Файл проверяется целиком: показываются **все** ошибки сразу, не только первая.
E1 и E2 — под зоной загрузки; E3–E7 — в сводке и таблице.

| Код | Условие | Текст (дословно) | Где |
|---|---|---|---|
| E1 | расширение не `.xlsx` | Загрузите файл в формате .xlsx | под зоной загрузки |
| E2 | размер больше лимита | Файл больше лимита | под зоной загрузки |
| E3 | нет обязательной колонки | В файле нет колонки «<название>». Скачайте шаблон и перенесите данные в него | таблица ошибок, «Строка» = — |
| E4 | нет строк с данными | В файле нет данных для сверки | таблица ошибок, «Строка» = — |
| E5 | пустое обязательное поле | Не заполнено обязательное поле | таблица ошибок |
| E6 | некорректная дата | Некорректная дата. Формат — ДД.ММ.ГГГГ | таблица ошибок |
| E7 | договор не найден | Договор <номер> не найден среди договоров ГК «<ГК>» со СК «<СК>» | таблица ошибок |

Сводка ошибок:

| Элемент | Текст |
|---|---|
| Заголовок сводки (`h3`, `tabindex="-1"`, фокус после проверки) | Файл не принят. Исправьте ошибки и загрузите файл снова. |
| Счётчик | Ошибок: N (1 ошибка / 2 ошибки / 5 ошибок) |
| `caption` таблицы (sr-only) | Ошибки файла: строка, колонка, описание |
| Колонки | Строка · Колонка · Ошибка |
| Нет номера строки | — (с `sr-only`: «для всего файла») |
| Нет колонки | — |
| Обязательные колонки для E5 | № договора · ФИО · Дата рождения · Программа |

Правила:

- E3 выводится отдельной строкой на каждую отсутствующую обязательную колонку.
- E5/E6 — отдельной строкой на каждую ячейку; сортировка: по номеру строки,
  затем по порядку колонок шаблона.
- Ошибка не стирает выбранный файл: пользователь видит имя файла и может
  заменить его.
- Фокус после ответа проверки: заголовок сводки; `aria-live="assertive"` не
  используется (избегаем двойного чтения) — сводка получает фокус.

### 4.1. Колонки списка (desktop, ≥ 768px)

| # | Колонка | Содержимое | Формат |
|---|---|---|---|
| 1 | Дата и время | дата запуска | ДД.ММ.ГГГГ, ЧЧ:ММ |
| 2 | ГК | название | полный, перенос |
| 3 | СК | название | полный, перенос |
| 4 | Кто запустил | ФИО | «Фамилия Имя Отчество»; при отсутствии — username |
| 5 | Статус | статус сверки | текст + нейтральный чип; без цвета как единственного признака |
| 6 | Расхождений | «Итого расхождений» | целое с разделителем разрядов; для не-«Готова» — «—» |
| 7 | Исходный файл | имя файла | ссылка на скачивание; `download`; имя обрезается посередине |
| 8 | Действия | «Открыть» / «Повторить» | ссылка + вторичная кнопка |

Правила:

- Сортировка фиксированная: новые сверху; сортируемых заголовков нет.
- Клик по строке открывает результат; доступная точка входа — ссылка
  «Открыть сверку от <дата>» в первой ячейке (растянута на строку). Клики по
  ссылке файла и кнопке «Повторить» строку не открывают.
- «Повторить» доступна для любого статуса, создаёт новую сверку; прежняя не
  меняется. Во время запроса: «Запускаем…», кнопка disabled, повторный клик
  игнорируется.
- Для «Ошибка обработки» в списке нет inline-причины; причина — на экране
  результата (S-RES-ERROR). Экспорт для такого статуса недоступен (OD-12).
- Для «Обрабатывается» ссылка «Открыть» ведёт на экран с состоянием
  «Сверка выполняется»; «Расхождений» = «—».

### 4.2. Список на мобильном (< 768px)

Таблица превращается в стек карточек (паттерн — gap DS, см. `ds-gaps.md`):

- Строка 1: дата/время + статус.
- Строка 2: ГК — СК.
- Строка 3: «Кто запустил: <ФИО>».
- Строка 4: «Расхождений: N» (или «—»).
- Строка 5: файл (ссылка) и действия «Открыть» / «Повторить».
- Вся карточка — цель клика, но ссылка «Открыть» остаётся фокусируемой.

## 5. Форматы и правила письма

- Даты: `ДД.ММ.ГГГГ`; дата+время: `ДД.ММ.ГГГГ, ЧЧ:ММ`; в API/URL — ISO-8601.
- Числа: разделитель разрядов — неразрывный пробел (`1 240`), без знака «+».
- «—» (em dash) — отсутствие значения; не «0» и не пустая ячейка.
- Склонения: 1 сверка / 2 сверки / 5 сверок; 1 ошибка / 2 ошибки / 5 ошибок.
- Никаких «Успешно!», «Ой!»; тон нейтральный, действие — в повелительном
  наклонении («Выберите», «Загрузите»).
- Названия ГК/СК/ФИО/программ не переписываются, не сокращаются и не
  нормализуются в UI.
- Ошибка всегда содержит: что произошло + что сделать. Если действие
  невозможно — почему.

## 6. Доступность и состояния

- Каждое поле имеет видимый `<label>`; helper связан через
  `aria-describedby`; ошибка — `aria-invalid="true"`.
- `disabled` СК объясняется видимым helper, а не только атрибутом.
- Все динамические сообщения — в контейнерах с `role="status"`/`role="alert"`
  и `aria-live`; визуально они находятся рядом с источником.
- Фокус: после ошибок файла — на заголовок сводки; после запуска — на
  заголовок истории (или на экран результата при переходе).
- Touch targets ≥ 44×44 px; drag-and-drop дублируется кнопкой.
- `prefers-reduced-motion` — без анимаций; индикатор загрузки текстовый.
- На 360 px форма в одну колонку, кнопки на всю ширину; ни один текст не
  обрезается, кроме имени файла (с `title` и доступным полным именем).
