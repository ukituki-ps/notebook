# Design language — f-v5-sverka

Фиксирует визуальный и поведенческий язык двух маршрутов сверки в рамках
Notebook DS 1.0.1. Ничего не меняет в `design/`, `web/` и DS-релизе.

## 1. Принципы

1. **Сначала ответ, потом данные.** Экран результата за 3 секунды отвечает:
   «сверка готова?», «сколько расхождений?», «есть ли предупреждения?».
2. **Ошибка — рядом с причиной и с действием.** E1/E2 — под зоной загрузки,
   E3–E7 — сводка + таблица, с фокусом на сводку.
3. **Данные не сокращаются.** ФИО, программы, номера договоров и заявок
   переносятся и никогда не обрезаются; сокращается только имя файла.
4. **Цвет — не единственный признак.** Категория, отличие, статус и
   предупреждение всегда имеют текст/метку; подсветка лишь усиливает.
5. **Мобильный — не уменьшенный desktop.** На < 768 px строки таблицы — это
   карточки, фильтры — disclosure, свод — горизонтальный скролл с закреплённым
   договором.
6. **URL — состояние.** Фильтры результата (`category`, `contract`, `q`,
   `ref`) живут в query: ссылку можно передать, «назад» работает.
7. **Пусто ≠ ошибка ≠ нет результатов фильтра.** Три разных состояния и три
   разных текста.

## 3. Раскладка

- **`/sverka`:** одна колонка, `max-width: 640px`, как текущий `.app`;
  карточки друг под другом, gap 16–24 px.
- **`/sverka/{runId}`:** широкая колонка `max-width: 1120px` (GAP-09);
  шапка и предупреждения — на всю ширину, свод и список — в карточках.
- **Сетка таблиц:** линии `--border-subtle` 1 px; плотность строки —
  `space-2` (8 px) по вертикали, `space-3` (12 px) по горизонтали; шапка
  sticky; первая колонка sticky на горизонтальном скролле.
- **Числовые колонки:** выравнивание вправо, `font-variant-numeric:
  tabular-nums`, разделитель разрядов — неразрывный пробел.
- **Мобильные карточки:** `primitives/card`-контейнер, внутренние разделители
  `--border-subtle`, пары «СК → система» подписаны.

## 4. Типографика

- Один `h1` на экран; `h2` — секции (Новая сверка, История сверок, Свод,
  Расхождения); `h3` — подсекции и заголовки сводок ошибок.
- Body 16 px; мета и вспомогательный текст — `--muted`, но не меньше 16 px
  (нет токена 14 px).
- Числа в таблицах — tabular; даты — `ДД.ММ.ГГГГ`, дата+время —
  `ДД.ММ.ГГГГ, ЧЧ:ММ`.
- Длинные значения: `overflow-wrap: anywhere`; номера — `nowrap`; никаких
  `text-overflow: ellipsis` для данных.

## 5. Цвет и семантика

| Смысл | Вид |
|---|---|
| Расхождение (категория) | тон «внимание»: `--danger` текст/рамка на `--danger-bg` |
| Справочная категория | нейтральный: `--text` на `--bg`, рамка `--border-subtle` |
| Совпало | нейтральный, без акцента |
| Отличающееся значение | `--danger-bg` фон + левая граница 3 px `--danger` + sr-only «отличается» |
| Предупреждение W1/W2 | нейтральная плашка с меткой «Предупреждение» (не красная: это не ошибка) |
| Ошибка | `primitives/error`: `--danger`, `--danger-bg` |
| Ссылка/действие | `--accent`, hover `--accent-dark` |
| Недоступно/«—» | `--muted` |

Запрещено: кодировать 13 категорий 13 цветами; использовать цвет без
текстового ярлыка; вводить зелёный/оранжевый без токенов и проверки контраста.

## 6. Состояния и обратная связь

- Загрузка — текст + `aria-busy`; без скелетонов и спиннеров, пока нет
  компонента (GAP-12).
- Ошибка — `role="alert"`, рядом с источником; всегда «что случилось» +
  «что сделать».
- Успех/статус — `role="status"`, `aria-live="polite"`; не toast.
- Фокус после ошибки файла — на заголовок сводки; после запуска — на историю
  или на экран результата; фоновое обновление не перехватывает фокус.
- Анимации — только нативные; `prefers-reduced-motion` отключает всё
  необязательное.

## 7. Тон и текст

- Нейтральный, без восклицаний и эмодзи.
- Кнопки — глагол + объект: «Запустить сверку», «Скачать шаблон»,
  «Выгрузить в Excel», «Повторить», «Сбросить фильтры».
- «Повторить» в истории = новая сверка тем же файлом; прежняя не меняется.
- Не обещать автоматического ретрая при «Ошибка обработки» (OD-12).
- Склонения и форматы — см. `content-specs/*.md`.

## 8. Responsive

| Диапазон | Форма/история | Результат |
|---|---|---|
| ≥ 1024 px | 640 px одна колонка | 1120 px; таблицы с sticky header + first column |
| 768–1023 px | 640 px | таблицы со скроллом; второстепенные колонки скрыты под «Подробнее» |
| < 768 px | карточки истории; форма в одну колонку | свод со скроллом; расхождения — карточки; фильтры — `<details>` |

Above the fold на 360×640:

- запуск: `h1`, ГК, СК, зона файла;
- результат: назад, `h1`, «ГК — СК», статус + «Итого расхождений», W1/W2;
- обработка: «Сверка выполняется» + обещание автообновления.

## 9. Доступность (минимум)

- Контраст AA: `--text`/`--card` 15.9:1, `--muted`/`--card` 6.0:1,
  `--danger`/`--danger-bg` 5.7:1, белый/`--accent` 4.6:1.
- Таблицы: `<caption>`, `<th scope="col">`, заголовки строк при необходимости.
- Все интерактивные элементы — ≥ 44×44 px, видимый `:focus-visible`.
- Ссылки в новой вкладке помечены для скринридера.
- Подсветка отличий дублируется текстом.
- Ошибки связаны с полями через `aria-describedby`, `aria-invalid`.

## 10. Non-goals языка

- Новые DS-компоненты, изменение `design/registry.json`, `design/tokens.json`.
- React/Tailwind, CSS-in-JS, иконочные библиотеки.
- Модальные окна, toast, тултипы, кастомные dropdown/datepicker.
- Тёмная тема, кастомные шрифты, плотный «dashboard»-стиль.
- Пользовательская сортировка колонок, drag-and-drop строк, inline-редактирование.
- Печатная версия и PDF.
